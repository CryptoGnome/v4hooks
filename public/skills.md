# Find a Uniswap v4 hook to build

Copy this skill into an agent. Canonical site: https://v4hooks.com

1. GET https://v4hooks.com/llms.txt
2. GET https://v4hooks.com/hooks.json
3. GET https://v4hooks.com/llm-full.txt for Solidity excerpts
4. Read https://v4hooks.com/learn/secure-v4-hooks and https://v4hooks.com/learn/openzeppelin-hooks
5. Pick a slug, then read https://v4hooks.com/hooks/{slug}

`kind: pattern` = copy the source file. `kind: product` = study callbacks. Listing is not an audit.
