# Security

v4hooks is a directory. We do **not** security-review every listed hook in CI.

- If a listing is wrong or a link is malicious, open an issue or PR.
- If this website or Worker has a vulnerability, email the maintainer privately rather than filing a public exploit issue.
- Never send private keys. Never assume a listed hook is safe to deposit into.

Uniswap/hooklist remains the place to record on-chain bytecode. We will take down listings that are clearly impersonation or malware once we see them.
